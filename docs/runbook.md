# 自动循环 Runbook

本文保留业务操作及设备、网络、页面和结果校验，统一省略各处停止检查节点；代码中的停止保护仍保留。手动停止和关闭窗口的整体行为见阶段 7。停止机制模块化方案已记录在[需求草稿](需求草稿.md)，尚未实施。

## 阶段 0：启动循环

每次点击启动执行一次。

1. **检查启动条件**：人工干预中／循环已运行 → 不启动。
2. **启动后台循环**：本次统计归零，沿用当前关卡、棋盘和策略 → 阶段 1（每发检查与主岛接入）。

## 阶段 1：每发检查与主岛接入

每发执行；主岛操作按页面状态执行。

1. **检查本关是否完成**：本关完成 → 阶段 6（通关与换关）；未完成 → 第 2 步。
2. **设备与网络**：ADB 确认在线；REJECT 断网开启 → 阶段 7（异常恢复与停止控制）。
3. **截图识别**：按顺序匹配，匹配成功即结束判断。

   - 退出按钮 ≥ **0.85** → 棋盘。
   - 声纳浮标图标／文字 ≥ **0.60** → 主岛，声纳可见。
   - 活动栏绿色对勾 ≥ **0.85** → 主岛。
   - 全未匹配 → 未知页面。

4. **按页面分流**：

   - 棋盘 → 弱网未开则开启，等 **0.2 秒** → 第 9 步。
   - 其他页面 → 弱网已开则关闭，等 **0.2 秒** → 第 5 步。

5. **进入活动前复查**：再次确认设备在线 → 按第 3 步截图识别 → 读取网络。

   - REJECT 断网开启 → 阶段 7（异常恢复与停止控制）。
   - REJECT 断网关闭 → 按页面分流：

     - 棋盘 → 弱网未开则开启，等 **0.2 秒** → 再次按第 3 步判断页面：

       - 仍在棋盘 → 第 9 步。
       - 未在棋盘 → 阶段 7（异常恢复与停止控制）。

     - 其他页面 → 第 6 步。

6. **等待主岛**：活动栏绿色对勾 ≥ **0.85** → 继续；最多等 **45 秒**。
7. **寻找声纳浮标图标／文字**：

   - 任一个 ≥ **0.60** → 第 8 步。
   - 未找到 → 上划 **（640，500）→（640，200）**，滑动 **0.8 秒** → 等 **0.5 秒** → 继续识别，阈值 **0.60**，最多等 **60 秒**；找到 → 第 8 步。

8. **再次寻找活动栏绿色对勾**：≥ **0.85** → 点击识别中心坐标 → 等 **0.4 秒** → 阶段 2（进入活动棋盘）→ 返回第 9 步；查找最多等 **20 秒**。
9. **复查网络＋页面**：读取网络 → 按第 3 步再次截图识别。

   - 棋盘＋弱网开＋REJECT 断网关 → 阶段 3（单格探测与结果识别）。
   - 未通过 → 阶段 7（异常恢复与停止控制）。

识别等待：每 **0.5 秒**重试，找到即继续；识别超时／复查失败 → 阶段 7（异常恢复与停止控制）。

弱网开关后的 **0.2 秒**仅在实际切换时等待；状态无需改变时直接继续。

## 阶段 2：进入活动棋盘

接阶段 1 第 8 步，活动栏已打开。

1. **准备弱网**：沿用阶段 1 第 5 步读取的网络状态。

   - 未开启 → 开启，等 **0.2 秒**。
   - 已开启 → 继续。

2. **等待列表**：等 **0.2 秒** → 再等 **0.4 秒**。
3. **上划列表 2 次**：**（1000，660）→（1000，180）**；每次滑动 **0.3 秒**，滑后等 **0.2 秒**。
4. **点击活动入口**：等 **0.7 秒** → 点击 **（1205，644）**；无菜单／入口识图确认。
5. **等待退出按钮**：每 **0.5 秒**重试，最多等 **15 秒**。

   - 相似度 ≥ **0.85** → 第 6 步。
   - 超时 → 下方异常分流。

6. **关闭开始提示**：等 **0.4 秒** → 点击 **（300，140）** → 等 **0.5 秒**；不检查提示是否存在。
7. **再次截图判断页面**：按阶段 1 第 3 步的顺序和阈值识别。

   - 棋盘 → 第 8 步。
   - 其他页面 → 下方异常分流。

8. **重新读取网络**：

   - 弱网开启 → 返回阶段 1（每发检查与主岛接入）第 9 步。
   - 弱网关闭 → 下方异常分流。

**异常分流：**

- 本次流程开启过弱网 → 先尝试关闭，成功后等 **0.2 秒** → 阶段 7（异常恢复与停止控制）。
- 本次流程未开启弱网 → 直接进入阶段 7（异常恢复与停止控制）。

## 阶段 3：单格探测与结果识别

1. **设备与选格**：ADB 确认在线 → 检查棋盘坐标映射 → 沿用待探测格，无待探测格则由策略选格 → 取得该格中心坐标 **（x，y）**。
2. **点击前确认棋盘**：等待退出按钮 ≥ **0.85**，最多 **6 秒**。

   - 找到 → 第 3 步。
   - 超时 → 再截图判断页面 → 阶段 7（异常恢复与停止控制）。

3. **保存点击前截图** → 点击目标格 **（x，y）** → 等 **0.3 秒**。
4. **退出棋盘**：单次截图查找退出按钮。

   - ≥ **0.85** → 点击识别中心坐标 → 等 **0.5 秒**。
   - 未找到 → 阶段 7（异常恢复与停止控制）。

5. **打开活动栏**：查找活动栏绿色对勾 ≥ **0.85**，最多 **20 秒** → 点击识别中心坐标 → 等 **0.4 秒**。
6. **重进活动**：另等 **0.7 秒** → 点击 **（1205，644）**；沿用当前网络，本次不上划列表。
7. **确认棋盘**：等待退出按钮 ≥ **0.85**，最多 **15 秒**。
8. **关闭开始提示**：等 **0.4 秒** → 点击 **（300，140）** → 等 **0.5 秒**；不检查提示是否存在。
9. **截图与识别**：保存结果截图 → 读取前后截图 → 按变化、灰度、颜色等特征判断 → 保存诊断图。命中采用多条件规则，**0.85** 是其中一条评分分支的门槛。
10. **补帧确认**：

    - 结果未知／未打开，或置信度 **＜0.68** 且评分与 **0.85** 的差值 **≤0.08** → 补截 **1 帧** → 重新识别两帧；无额外固定等待。
    - 任一帧命中 → 优先命中；否则按结果数量决定，同票优先级：**未命中 ＞ 未打开 ＞ 未知**。
    - 无需补帧 → 保留首次结果。

11. **写回结果**：

    - 明确命中／未命中＋目标格一致 → 写入棋盘和策略 → 确认击沉情况 → 更新统计。
    - 仍未知／未打开，或目标格不一致 → 阶段 7（异常恢复与停止控制）。

12. **按结果分流**：

    - 本关完成 → 阶段 6（通关与换关），先执行最后结果提交。
    - 本关未完成＋命中／击沉 → 阶段 4（命中后的处理）。
    - 本关未完成＋未命中 → 阶段 5（未命中后的处理）。

等待识别时，每次失败后最多等 **0.5 秒**再查；超时／检查失败 → 阶段 7（异常恢复与停止控制）。目标格坐标随本发选格和当前关卡映射变化。

## 阶段 4：命中后的处理

适用于命中／击沉，且本关尚未完成。

1. **读取网络状态**：

   - REJECT 断网开启／弱网关闭 → 阶段 7（异常恢复与停止控制）。
   - REJECT 断网关闭＋弱网开启 → 第 2 步。

2. **恢复联网**：清除弱网和 REJECT 断网规则 → 等 **0.2 秒**。
3. **等待命中结果提交**：另等 **5 秒**。
4. **重新执行探测准备**：执行阶段 1（每发检查与主岛接入）第 **2～9 步**。

   - 已在棋盘 → 按需开启弱网，开启后等 **0.2 秒** → 完成准备复查。
   - 未在棋盘 → 按条件执行主岛接入及阶段 2（进入活动棋盘）→ 完成准备复查。
   - 本次准备复查通过 → 返回本阶段第 5 步。

5. **额外复查一次**：重新读取网络 → 再次截图判断页面，识别顺序和阈值沿用阶段 1 第 3 步。

   - 棋盘＋REJECT 断网关＋弱网开 → 第 6 步。
   - 未通过 → 阶段 7（异常恢复与停止控制）。

6. **本发收尾**：标记恢复完成 → 预选下一格 → 记录本发完成 → 阶段 1（每发检查与主岛接入），开始下一发。

本阶段通常无点击；需要重新接入时，按阶段 1、2 的顺序使用：
**主岛上划（640，500）→（640，200）**、**列表上划（1000，660）→（1000，180）**、**活动入口（1205，644）**、**安全位置（300，140）**。各项等待保留在对应接入步骤中。

## 阶段 5：未命中后的处理

适用于未命中，且本关尚未完成。

1. **读取网络状态**：

   - REJECT 断网开启／弱网关闭 → 阶段 7（异常恢复与停止控制）。
   - REJECT 断网关闭＋弱网开启 → 第 2 步。

2. **开启 REJECT 断网** → 等 **0.2 秒**；弱网保持开启。
3. **等待重试按钮**：相似度 ≥ **0.85**，最多 **20 秒**；每次识别失败后最多等 **0.5 秒**再查。

   - 找到 → 保留识别中心坐标 → 第 4 步。
   - 超时 → 保存相似度最高的一帧 → 第 4 步。

4. **关闭 REJECT 断网** → 等 **0.2 秒**；根据第 3 步结果分流：

   - 找到按钮 → 第 5 步。
   - 识别超时 → 报错 → 阶段 7（异常恢复与停止控制）；此时弱网仍开启。

5. **点击重试**：另等 **0.1 秒** → 点击第 3 步保留的中心坐标 → 等 **0.5 秒**。
6. **关闭弱网** → 等 **0.2 秒**。
7. **重新接入活动**：ADB 确认在线 → 按阶段 1 第 3 步截图判断页面 → 读取网络。

   - REJECT 断网开启 → 阶段 7（异常恢复与停止控制）。
   - REJECT 断网关闭＋棋盘 → 弱网未开则开启，等 **0.2 秒** → 再次截图判断页面 → 第 8 步。
   - REJECT 断网关闭＋其他页面 → 执行阶段 1（每发检查与主岛接入）第 **6～8 步**，其中调用阶段 2（进入活动棋盘）；本次接入结束 → 返回本阶段第 8 步。

8. **恢复后复查**：重新读取网络 → 再次截图判断页面，识别顺序和阈值沿用阶段 1 第 3 步。

   - 进入结果、当前页面均为棋盘＋REJECT 断网关＋弱网开 → 第 9 步。
   - 未通过 → 阶段 7（异常恢复与停止控制）。

9. **本发收尾**：标记恢复完成 → 预选下一格 → 记录本发完成 → 阶段 1（每发检查与主岛接入），开始下一发。

**等待重试期间发生异常**：先尝试关闭本流程开启的 REJECT 断网，成功后等 **0.2 秒** → 阶段 7（异常恢复与停止控制）。等待重试期间的手动停止处理见阶段 7。

重新接入涉及的坐标沿用阶段 1、2：**主岛上划（640，500）→（640，200）**、**列表上划（1000，660）→（1000，180）**、**活动入口（1205，644）**、**安全位置（300，140）**。各项等待保留在对应步骤中。

## 阶段 6：通关与换关

本关完成由**策略层最终确认**：剩余潜艇数为 **0**。胜利画面在第 5 步识别。

**入口分流：**

- 本发由策略层最终确认全部潜艇 → 第 1 步。
- 阶段 1 的循环入口读取策略完成状态，确认本关已完成 → 直接进入第 5 步。

1. **恢复联网**：清除弱网和 REJECT 断网规则 → 等 **0.2 秒**。
2. **提交最后结果**：

   - 本发命中／击沉 → 另等 **5 秒**。
   - 本发未命中 → 直接继续。

3. **记录当前状态**：读取网络 → 截图判断页面，顺序和阈值沿用阶段 1 第 3 步；此处仅记录状态。
4. **结束本发**：标记恢复完成 → 调用选格（本关已完成，返回空）→ 记录本发完成 → 返回阶段 1（每发检查与主岛接入）第 1 步 → 读取策略完成状态 → 结束本关探测 → 第 5 步。

5. **等待胜利图案**：相似度 ≥ **0.85**，最多 **12 秒**。

   - 找到 → 第 6 步。
   - 超时 → 下方异常停止分支。

6. **跳过结算**：点击 **（300，140）** → 等 **1 秒** → 再点击 **（300，140）** → 等 **0.3 秒**。
7. **再次查找胜利图案**：阈值 **0.85**，最多 **0.5 秒**。

   - 仍找到，结算操作未满 **3 轮** → 返回第 6 步。
   - 仍找到，已满 **3 轮** → 下方异常停止分支。
   - 未找到 → 第 8 步。

8. **确认下一关棋盘**：等待退出按钮 ≥ **0.85**，最多 **15 秒**。

   - 找到 → 第 9 步。
   - 超时 → 下方异常停止分支。

9. **建立下一关**：通关计数加一 → 关卡号加一 → 创建新棋盘、坐标映射和策略 → 预选第一格 → 同步界面 → 阶段 1（每发检查与主岛接入）。

等待识别时，每次失败后最多等 **0.5 秒**再查，找到即继续。

**异常分流：**

- 第 1～4 步发生可恢复异常 → 阶段 7（异常恢复与停止控制）的异常重启分支。
- 胜利识别／结算／换关失败 → 阶段 7（异常恢复与停止控制）的异常停止分支，尝试恢复网络后结束循环。

## 阶段 7：异常恢复与停止控制

**入口分流：**

- 单发可恢复异常 → **异常重启**。
- 重启次数耗尽／其他异常／胜利结算或换关失败 → **异常停止**。
- 点击停止／关闭窗口 → 下方对应分支。

**异常重启**

1. **检查重启次数**：每发最多 **3 次**，同一发累计使用。

   - 尚有次数 → 次数加一 → 第 2 步。
   - 次数耗尽 → 异常停止。

2. **检查设备和游戏**：ADB 确认在线 → 确认游戏已安装 → 关闭游戏 → 等 **1 秒**。
3. **恢复并启动**：清除弱网和 REJECT 断网规则 → 等 **0.2 秒** → 启动游戏 → 等 **10 秒**。
4. **重新接入**：执行阶段 1（每发检查与主岛接入）第 **2～9 步**；接入完成 → 返回第 5 步。
5. **额外复查**：截图判断页面 → 读取网络。

   - 棋盘＋弱网开＋REJECT 断网关 → 第 6 步。
   - 未通过 → 返回第 1 步。

   页面识别沿用阶段 1：退出按钮 **≥ 0.85**；声纳浮标图标／文字 **≥ 0.60**；活动栏绿色对勾 **≥ 0.85**。

6. **准备续接本发**：更新本发进度标记 → **再次执行阶段 1 第 2～9 步** → 返回第 7 步。
7. **按已完成进度分流**：

   - **尚无明确识别结果** → 清除旧截图进度，保留原目标格 → 阶段 3（单格探测与结果识别）。
   - **已识别命中／击沉，恢复未完成** → 点击原目标中心 **（x，y）** → 等 **0.3 秒** → 沿用识别结果，补齐尚未完成的策略同步 → 阶段 4（命中后的处理）；策略已确认本关完成 → 阶段 6（通关与换关）。
   - **已识别未命中，恢复未完成** → 沿用识别结果，补齐尚未完成的策略同步 → 将本次重启记为恢复完成 → 本发收尾。
   - **本发恢复已完成** → 沿用已完成进度 → 本发收尾。

**本发收尾**：预选下一格 → 记录本发完成 → 阶段 1（每发检查与主岛接入）。

第 **2～5 步**发生异常 → 返回第 1 步；续接本发再次发生可恢复异常 → 使用本发剩余重启次数。

重新接入坐标沿用原步骤：**主岛上划（640，500）→（640，200）**；**列表上划（1000，660）→（1000，180）**；**活动入口（1205，644）**；**安全位置（300，140）**。补点坐标 **（x，y）**取自本发已记录的格子中心。

**异常停止**

1. **重启次数耗尽时先清理**：恢复网络 → 成功后等 **0.2 秒** → 读取网络，确认弱网和 REJECT 断网均关闭；失败最多尝试 **3 次**。
2. **后台退出清理**：再尝试恢复网络 → 成功后等 **0.2 秒** → 结束循环。

   - 其他异常／胜利结算或换关失败 → 直接执行本步。
   - 重启耗尽后的本次清理若报错 → 异常处理再尝试恢复一次，成功后等 **0.2 秒**。

**手动停止**

1. **点击停止** → 等待当前不可中断动作完成后结束本次循环；已开始的识别、策略写入和棋盘同步完整执行。
2. **等待重试期间停止** → 尝试关闭本流程开启的 REJECT 断网，成功后等 **0.2 秒** → 退出。
3. **保留当前关卡、棋盘和策略**；停止操作本身保留当前网络状态。
4. **再次启动** → 阶段 0（启动循环）；统计归零，重新建立本发执行进度。

**关闭窗口**

请求停止 → 等待后台退出 → 恢复网络，成功后等 **0.2 秒** → 关闭窗口；清理失败则记录错误后关闭。
