# 循环控制说明

本文收录启动、循环调度、异常重启和停止，沿用原有数字编号。阶段 1～6 的具体操作见 [runbook](runbook.md)；调用后返回本文标明的步骤。

停止机制模块化方案已记录在[需求草稿](需求草稿.md)，尚未实施。

## 阶段 0：启动与循环调度

### 0.1 启动循环

每次点击启动循环时执行一次。

1. **检查启动条件**：人工干预中／循环已运行 → 不启动。
2. **启动后台循环**：本次统计归零，沿用当前关卡、棋盘和策略 → 0.2（多关调度）。

### 0.2 多关调度

1. **运行当前关**：将当前棋盘和策略交给 0.3（单关循环），等待返回。
2. **根据返回原因分流**：本关完成 → 调用 runbook 6.2（胜利结算与换关）；停止或异常结束 → 按阶段 7 退出。
3. **建立下一关**：6.2 成功返回 → 通关计数加一 → 关卡号加一 → 创建新棋盘、坐标映射和策略 → 预选第一格 → 同步界面 → 返回第 1 步。

### 0.3 单关循环

1. **检查本关是否完成**：读取策略完成状态；本关完成 → 返回 0.2 第 2 步；未完成 → 第 2 步。本步无需截图。
2. **执行一发**：调用 runbook 阶段 1 准备，再执行阶段 3；按结果进入阶段 4、阶段 5 或 6.1。单发异常按阶段 7 处理。
3. **接收本发完成结果**：本发收尾后返回本层，再从第 1 步判断是否继续。

## 阶段 7：异常恢复与停止控制

**入口分流：**

- 单发可恢复异常 → **异常重启**。
- 重启次数耗尽／其他异常／胜利结算或换关失败 → **异常停止**。
- 点击停止／关闭窗口 → 下方对应分支。

**异常重启**

1. **检查重启次数**：每发最多 **3 次**，同一发累计使用。

   - 尚有次数 → 次数加一 → 第 2 步。
   - 次数耗尽 → 异常停止。

2. **检查设备和游戏**：ADB 确认在线 → 确认游戏已安装 → 关闭游戏 → 等 **1 秒**。
3. **恢复并启动**：清除弱网和 REJECT 断网规则 → 等 **0.2 秒** → 启动游戏 → 等 **10 秒**。
4. **重新接入**：执行 runbook 阶段 1（每发检查与主岛接入）全流程；接入完成 → 返回第 5 步。
5. **额外复查**：截图判断页面 → 读取网络。

   - 棋盘＋弱网开＋REJECT 断网关 → 第 6 步。
   - 未通过 → 返回第 1 步。

   页面识别沿用阶段 1：退出按钮 **≥ 0.85**；声纳浮标图标／文字 **≥ 0.60**；活动栏绿色对勾 **≥ 0.85**。

6. **准备续接本发**：更新本发进度标记 → **再次执行 runbook 阶段 1 全流程** → 返回第 7 步。
7. **按已完成进度分流**：

   - **尚无明确识别结果** → 清除旧截图进度，保留原目标格 → 阶段 3（单格探测与结果识别）。
   - **已识别命中／击沉，恢复未完成** → 点击原目标中心 **（x，y）** → 等 **0.3 秒** → 沿用识别结果，补齐尚未完成的策略同步 → 阶段 4（命中后的处理）；策略已确认本关完成 → 6.1（最后一发提交）。
   - **已识别未命中，恢复未完成** → 沿用识别结果，补齐尚未完成的策略同步 → 将本次重启记为恢复完成 → 本发收尾。
   - **本发恢复已完成** → 沿用已完成进度 → 本发收尾。

**本发收尾**：预选下一格 → 记录本发完成 → 返回 0.3 第 1 步。

第 **2～5 步**发生异常 → 返回第 1 步；续接本发再次发生可恢复异常 → 使用本发剩余重启次数。

重新接入坐标沿用 runbook 原步骤：**主岛上划（640，500）→（640，200）**；**列表上划（1000，660）→（1000，180）**；**活动入口（1205，644）**；**安全位置（300，140）**。补点坐标 **（x，y）**取自本发已记录的格子中心。

**异常停止**

1. **重启次数耗尽时先清理**：恢复网络 → 成功后等 **0.2 秒** → 读取网络，确认弱网和 REJECT 断网均关闭；失败最多尝试 **3 次**。
2. **后台退出清理**：再尝试恢复网络 → 成功后等 **0.2 秒** → 结束循环。

   - 其他异常／胜利结算或换关失败 → 直接执行本步。
   - 重启耗尽后的本次清理若报错 → 异常处理再尝试恢复一次，成功后等 **0.2 秒**。

**手动停止**

1. **点击停止** → 等待当前不可中断动作完成后结束本次循环；已开始的识别、策略写入和棋盘同步完整执行。
2. **等待重试期间停止** → 尝试关闭本流程开启的 REJECT 断网，成功后等 **0.2 秒** → 退出。
3. **保留当前关卡、棋盘和策略**；停止操作本身保留当前网络状态。
4. **再次启动** → 0.1（启动循环）；统计归零，重新建立本发执行进度。

**关闭窗口**

请求停止 → 等待后台退出 → 恢复网络，成功后等 **0.2 秒** → 关闭窗口；清理失败则记录错误后关闭。
