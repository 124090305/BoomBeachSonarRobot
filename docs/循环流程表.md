# 自动循环流程与等待时间

按当前自动循环整理；需求草稿尚未实施；未修改程序。

- 固定等待按表执行；最长等待找到即继续，截图与命令耗时另计。
- 识别等待通常间隔 0.5 秒重试；网络操作内部 0.2 秒已计入表格。

## 0、开启循环与接入循环

点击启动后从 0.1 开始；每一发开始会重复 0.2～0.5。

| 步骤 | 环节 | 操作 | 等待时间 |
|---|---|---|---|
| 0.1 | 开启循环 | 启动后台循环，沿用当前关卡、棋盘和策略 | 无固定等待 |
| 0.2 | 检查循环状态 | 有停止请求则停止；策略已完成则转到 6.2；否则开始本发 | 无固定等待 |
| 0.3 | 检查设备与网络 | 确认模拟器在线；强制断网仍开启则进入异常重启 | 无固定等待 |
| 0.4 | 判断当前画面 | 同一截图依次找退出按钮、声纳图标、声纳文字、绿色对勾；全部未找到则为未知页面 | 单次识别 |
| 0.5 | 接入棋盘 | 已在棋盘则确保弱网开启，再检查页面和网络；未在棋盘则先走阶段 1、2，返回后再检查 | 新开启弱网后等 0.2 秒；检查无固定等待 |

接下来：接入完成 → 阶段 3；未知页面先进入阶段 1 等待主岛，不立即重启。

## 1、进入主岛与识别确认

从主岛或未知页面接入时执行；未命中恢复也会回到这里。

| 步骤 | 环节 | 操作 | 等待时间 |
|---|---|---|---|
| 1.1 | 恢复加载条件 | 若弱网仍开启，先关闭弱网 | 执行关闭时等 0.2 秒 |
| 1.2 | 再次判断页面 | 再次检查页面和网络；若已到棋盘，确保弱网开启、复查页面并返回原流程 | 单次识别；新开启弱网后等 0.2 秒 |
| 1.3 | 等待主岛 | 查找绿色对勾，找到就确认主岛已加载；超时进入异常重启 | 最长 45 秒 |
| 1.4 | 查找声纳 | 先找声纳图标或文字；找不到就上划主岛一次，再继续找 | 滑动 0.8 秒，滑后等 0.5 秒；随后识别最长 60 秒 |
| 1.5 | 打开活动侧栏 | 重新查找绿色对勾，找到后点击 | 识别最长 20 秒；点击后等 0.4 秒 |

接下来：活动侧栏打开 → 阶段 2；声纳或按钮等待失败 → 阶段 7。

## 2、进入活动棋盘页面与识别确认

从主岛打开活动侧栏后执行。

| 步骤 | 环节 | 操作 | 等待时间 |
|---|---|---|---|
| 2.1 | 开启弱网保护 | 未开启则开启弱网，等待弱网生效和列表缓冲 | 新开启时 0.2＋0.2＋0.4 秒，共 0.8 秒；已开启时共 0.6 秒 |
| 2.2 | 上划活动列表 | 按固定坐标上划两次 | 每次滑动 0.3 秒，滑后等 0.2 秒 |
| 2.3 | 点击活动入口 | 等待后点击固定位置（1205，644） | 点击前等 0.7 秒 |
| 2.4 | 确认进入棋盘 | 等待退出活动按钮，找到就确认进入棋盘 | 最长 15 秒 |
| 2.5 | 关闭开始提示 | 等待后点击安全位置（300，140），不检查提示是否存在 | 点击前等 0.4 秒；点击后等 0.5 秒 |
| 2.6 | 进入后复查 | 再次判断页面，确认仍在棋盘，再检查弱网开启 | 无固定等待 |

接下来：正常接入：返回 0.5 做最终检查 → 阶段 3；恢复过程中调用：先返回对应恢复步骤。

## 3、单格探测

从策略选格开始，完成点击、截图、退出重进和结果判断。

| 步骤 | 环节 | 操作 | 等待时间 |
|---|---|---|---|
| 3.1 | 策略选格 | 沿用待探测格；没有目标时由策略选格，计算点击坐标 | 无固定等待 |
| 3.2 | 点击前复查 | 再次等待退出活动按钮；超时做一次页面诊断并报错 | 最长 6 秒；失败时另做单次识别 |
| 3.3 | 保存点击前截图 | 保存当前画面，作为本发对比基准 | 无固定等待 |
| 3.4 | 点击目标格 | 点击策略选出的格点 | 点击后等 0.3 秒 |
| 3.5 | 退出棋盘 | 查找退出活动按钮并点击；找不到进入异常重启 | 单次识别；点击后等 0.5 秒 |
| 3.6 | 重开活动侧栏 | 查找绿色对勾并点击 | 识别最长 20 秒；点击后等 0.4 秒 |
| 3.7 | 重新进入棋盘 | 再等待后点击固定入口；这次不上划列表，也不切换网络 | 再等 0.7 秒；与上一步合计等待 1.1 秒 |
| 3.8 | 确认返回棋盘 | 等待退出活动按钮出现 | 最长 15 秒 |
| 3.9 | 关闭开始提示 | 等待后点击安全位置（300，140） | 点击前等 0.4 秒；点击后等 0.5 秒 |
| 3.10 | 保存结果截图 | 保存重新进入后的画面 | 无固定等待 |
| 3.11 | 识别目标格 | 比较前后截图；结果模糊时补一帧，任一帧命中则优先命中，否则按数量和优先级判断 | 最多补 1 帧；无额外固定等待 |
| 3.12 | 记录并分流 | 明确结果写入棋盘和策略；击沉由逻辑层确认；结果仍不明确则进入异常重启 | 无固定等待 |

接下来：未通关：命中 → 阶段 4，未命中 → 阶段 5；全部潜艇确认 → 阶段 6；识别不明确 → 阶段 7。

## 4、单格探测成功

这里的成功指命中；击沉且本关未完成，也走此分支。

| 步骤 | 环节 | 操作 | 等待时间 |
|---|---|---|---|
| 4.1 | 确认网络 | 检查弱网开启、强制断网关闭 | 无固定等待 |
| 4.2 | 联网提交 | 恢复正常联网，等待命中结果提交 | 恢复网络内等 0.2 秒，再等 5 秒 |
| 4.3 | 恢复探测准备 | 重新执行 0.3～0.5；仍在棋盘则开启弱网，离开棋盘则先走阶段 1、2 | 沿用对应步骤等待；新开启弱网后等 0.2 秒 |
| 4.4 | 再次确认 | 准备通过后，再检查页面和网络 | 无固定等待 |
| 4.5 | 继续下一格 | 预选下一格，开始下一发；重复 0.2～0.5 后返回阶段 3 | 无额外固定等待 |

接下来：通常留在棋盘继续探测；准备或恢复失败 → 阶段 7。

## 5、单格探测失败

这里的失败指未命中；先断网并点击重试，异常时才关闭并重开游戏。

| 步骤 | 环节 | 操作 | 等待时间 |
|---|---|---|---|
| 5.1 | 确认网络 | 检查弱网开启、强制断网关闭 | 无固定等待 |
| 5.2 | 断网并等重试 | 开启强制断网，查找重试按钮 | 开启断网内等 0.2 秒；识别最长 20 秒 |
| 5.3 | 关闭强制断网 | 找到重试按钮后关闭强制断网，短暂等待 | 关闭断网内等 0.2 秒，再等 0.1 秒 |
| 5.4 | 点击重试 | 点击已找到的重试按钮 | 点击后等 0.5 秒 |
| 5.5 | 重新接回主岛流程 | 关闭弱网，返回 1.2 再次验证页面，按需执行阶段 1、2 | 关闭弱网内等 0.2 秒；其余沿用对应步骤等待 |
| 5.6 | 恢复后确认 | 回到棋盘后，再检查页面、弱网开启、强制断网关闭 | 无固定等待 |
| 5.7 | 继续下一格 | 预选下一格，开始下一发；重复 0.2～0.5 后返回阶段 3 | 无额外固定等待 |
| 5.8 | 重试超时分支 | 5.2 超时则保存最佳匹配截图，关闭强制断网，直接进入异常重启 | 关闭强制断网内等 0.2 秒 |

接下来：正常：5.1～5.7；等待重试超时：5.2 → 5.8 → 阶段 7。

## 6、胜利识别与换关

本发确认全部潜艇后执行；启动时策略已完成则直接从 6.2 开始。

| 步骤 | 环节 | 操作 | 等待时间 |
|---|---|---|---|
| 6.1 | 提交最后结果 | 恢复正常联网；最后一发命中则等待提交，再读取页面和网络状态 | 恢复网络内等 0.2 秒；命中时再等 5 秒 |
| 6.2 | 识别胜利 | 等待胜利图案出现；超时清理网络并停止 | 最长 12 秒 |
| 6.3 | 跳过结算 | 点击安全位置两次，再查胜利；仍存在则重复，最多 3 轮，仍未消失则报错停止 | 第一次点击后等 1 秒，第二次后等 0.3 秒；复查最长 0.5 秒 |
| 6.4 | 确认下一关 | 等待退出活动按钮；超时清理网络并停止 | 最长 15 秒 |
| 6.5 | 开始下一关 | 关卡号加一，建立新棋盘和策略；回到 0.2，准备完成后进入阶段 3 | 无固定等待 |

接下来：换关后继续循环；胜利识别失败直接停止，不走本发异常重启。

## 7、异常重启与用户暂停

7.1～7.5 为异常恢复；7.6～7.8 按用户操作分别执行。

| 步骤 | 环节 | 操作 | 等待时间 |
|---|---|---|---|
| 7.1 | 关闭游戏 | 保持当时网络状态关闭游戏应用 | 关闭后等 1 秒 |
| 7.2 | 恢复网络并重开 | 清除弱网和强制断网，再启动游戏 | 恢复网络内等 0.2 秒；启动后等 10 秒 |
| 7.3 | 重新接入循环 | 执行 0.3～0.5，按需走阶段 1、2；准备通过后再复查页面和网络 | 沿用对应步骤等待 |
| 7.4 | 继续当前这一发 | 更新恢复进度并再次做准备检查；未明确则重探原格，已命中且恢复未完成则补点提交，已未命中则保留结果继续 | 补点后等 0.3 秒；已完成恢复则保留完成标记 |
| 7.5 | 重启额度用尽 | 每发累计最多重启 3 次；仍失败则清理网络并停止 | 清理并核验最多 3 次，每次恢复内等 0.2 秒；后台还会再恢复一次 |
| 7.6 | 用户暂停 | 点击停止，在可中断点退出；已开始同步结果则先完成；通常保留网络，等待重试时先关闭本流程开启的强制断网 | 等待当前不可中断动作结束，无统一时长 |
| 7.7 | 用户继续 | 重新点击启动，保留内存棋盘和策略，从 0.1 接入；中间截图进度不续接 | 沿用接入流程等待 |
| 7.8 | 关闭程序 | 请求停止，等待后台退出，恢复网络后关闭窗口 | 后台等待无统一时长；恢复网络内等 0.2 秒 |

接下来：自动重启继续当前发，共用剩余额度；成功完成本发后才重置额度。单发可恢复异常进入重启，其余异常清理网络并停止。

## 重复检查的位置

| 位置 | 重复内容 |
|---|---|
| 0.4 → 1.2 | 未在棋盘时，会再次识别页面。 |
| 1.3 → 1.5 | 先确认绿色对勾存在，随后再次识别并点击。 |
| 2.4 → 2.6 → 0.5 → 3.2 | 初次进入棋盘后，点击格子前最多有四处退出按钮识别。 |
| 4.3 → 4.4 → 4.5 | 命中后准备、额外复查、下一发准备重复检查页面和网络。 |
| 5.5 → 5.6 → 5.7 | 未命中重进后，恢复检查和下一发准备再次确认。 |
| 2.5、3.9 | 进入和重进棋盘均固定点击安全位置并等待。 |
