# 人工测试模式：操作与验收

## 怎么操作

1. 打开原主界面，完全停止后勾选“人工测试模式”，再点原“启动循环”。点击、滑动、网络控制和重启仍真实执行，开启时会提醒一次。
2. 在弹窗查看截图及“期望／识别／判断”三行信息。下拉框初始为“请选择”；选好后查看接续动作，点击“确认继续”才提交。自动识别始终只供参考。
3. 需要点击位置时，可以确认蓝色自动候选，或点图选择橙色位置。点图只定位；没有有效位置不能提交“找到”。刷新后旧的人工点选失效，需重新点选再确认，防止把旧坐标用于新画面。
4. “详情”默认收起，内含模板原图、评分与参数、调用位置、近期记录和本发补帧。测试假定答案请勾选“本次答案为假定（测试）”；默认记录为按画面判断。
5. 提交后窗口保留，显示原流程正在执行的动作，下一次请求复用同一窗口。点击“停止”、关闭弹窗或关闭主窗口，均走原停止路径。

## 图片与结果

| 判断类型 | 图片和参考 | 人工决定 |
|---|---|---|
| 页面 | 原完整截图，原页面算法及模板相似度 | 页面类型或无法判断 |
| 单次模板 | 原单次截图、模板相似度与门槛 | 找到或未找到 |
| 等待模板、retry、声纳等待 | 按原间隔刷新截图及同帧参考；原 timeout 作为读条参考 | 找到、未找到或判定超时 |
| 单格 | 本发 before／after 与红色目标；原算法置信度，必要补帧在详情中 | HIT、MISS、未开启或无法判断本格结果 |

相似度和置信度均不代表正确率，无有效评分显示“—”。等待到点、机器找到目标均不会代答，读条到点后仍刷新；刷新保留下拉选项。普通单次判断及单格前后图保持静态。原图不被标记改写。

自动参考与人工结论分别记录到 `runtime/screenshots/manual_recognition/<会话编号>/` 的 JSON，并保存最终依据原图、前后图和参与判断的补帧。记录包含帧编号、坐标及“按画面／假定”来源。人工结果沿用原登记、恢复与通关路径，击沉由原策略校验。

已接受的单格结果先完整同步棋盘、策略和计数，再响应停止。停止后原人工改盘仍可使用，应用后保持停止；退出测试模式恢复原正式棋盘，确认实际游戏状态后再自行启动正式循环。
